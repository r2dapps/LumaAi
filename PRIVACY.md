# Privacy

Luma stores companion profiles, conversations, memories, settings and model metadata in the browser. The normal WebLLM workflow runs supported model inference in the browser.

Model downloads use the configured WebLLM model sources. Optional LAN mode sends requests to the local endpoint you configure. Optional browser speech recognition can use a remote service only when local-only speech is disabled and the browser chooses that service.

No analytics, login system or application server database is included in this package. Platform/browser features remain subject to the browser vendor and device.
